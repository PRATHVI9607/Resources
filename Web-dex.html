Why the split matters

Write HTML for meaning, not looks: a <button> works with the keyboard, screen readers and forms automatically; a <div> styled to look like one does not. Change the look later with CSS without touching the HTML.

DOMDocument Object Model: the live tree of elements the browser builds from your HTML. JavaScript and DevTools work on the DOM, which may differ from the source (the parser fixes errors and adds missing tags like tbody).
CSSOMThe parsed stylesheets. CSS is render-blocking: the page is not painted until the CSS in head has loaded.
Reflow and repaintChanging sizes or positions triggers layout again (expensive); changing colours only repaints; transform and opacity can skip both (cheap animations).

Use a semantic element when one fits; use <div> and <span> only for styling hooks with no meaning. Semantics give you free accessibility, better SEO, readable code and reader-mode support.

IN THIS ENTRYARIA adds accessibility information for assistive technologies when native HTML cannot express a widget. It changes nothing visually and adds no behaviour.

The five rules of ARIA

  1. If a native element does the job, use it: <button> not <div role="button">.
  2. Do not change native semantics unless you must (<h2 role="tab"> is wrong).
  3. Every interactive ARIA control must work with the keyboard.
  4. Never put aria-hidden="true" or role="presentation" on a focusable element.
  5. Every interactive element needs an accessible name.

No ARIA is better than bad ARIA: pages with ARIA average more accessibility errors than pages without.

@media (width >= 48rem) and (hover: hover) {
  .grid { grid-template-columns: repeat(3, 1fr); }
}
@media print {
  nav, .ads { display: none; }
}
@container

Styles based on the size (or style, or scroll state) of an ancestor container instead of the viewport.


.cards { container: cards / inline-size; }
@container cards (width > 30rem) {
  .card { display: grid; grid-template-columns: 8rem 1fr; }
}
@container style(--featured: true) { .card { border-color: gold; } }
@supports

Feature queries: apply styles only where a feature exists.


@supports (display: grid) and (not (display: inline-grid)) { }
@supports selector(:has(a)) {
  .card:has(img) { padding-top: 0; }
}
@layer

Cascade layers: declare an order of layers; later layers win over earlier ones regardless of specificity. Unlayered styles beat all layers.


@layer reset, base, components, utilities;
@layer components {
  .btn { padding: .5rem 1rem; }
}
@import url("theme.css") layer(base);
@import

Import another stylesheet. Must come first (after @charset and @layer statements). Blocks parallel downloading; prefer link tags or a bundler.


@import url("reset.css");
@import url("print.css") print;
@import url("theme.css") layer(theme) supports(display: grid);
@font-face

Load a web font file and give it a name.


@font-face {
  font-family: "Inter";
  src: url("/fonts/inter.woff2") format("woff2");
  font-weight: 100 900;   /* variable font range */
  font-style: normal;
  font-display: swap;     /* show fallback text first */
  unicode-range: U+0000-00FF;
}
@keyframes

Define an animation's steps (from/to or percentages).


@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.08); }
}
.badge { animation: pulse 1.5s ease-in-out infinite; }
@property

Register a typed custom property: animatable gradients, inheritance control, validated initial value.


@property --angle {
  syntax: "<angle>";
  inherits: false;
  initial-value: 0deg;
}
.spin { background: conic-gradient(from var(--angle), red, blue); animation: turn 3s linear infinite; }
@keyframes turn { to { --angle: 360deg; } }
@scope

Limit styles to a subtree, with an optional lower boundary (donut scope). Proximity decides between scopes.


@scope (.card) to (.card-content) {
  img { border-radius: 8px; }   /* only images in the card shell */
}
@starting-style

Starting values for an element's first style update: lets elements animate in from display:none or when inserted.


dialog[open] { opacity: 1; transition: opacity .3s, display .3s allow-discrete, overlay .3s allow-discrete; }
@starting-style { dialog[open] { opacity: 0; } }

IMPWhat is the difference between <section> and <div>?

section is a thematic group with a heading and appears in the document outline (as a region when named); div has no meaning and is only a styling hook.

IMPWhy should a button that only runs JavaScript inside a form have type="button"?

The default type of a button in a form is submit, so it would submit the form (and reload the page).

IMPWhich two attributes stop images causing layout shift?

width and height (the intrinsic size), so the browser reserves the aspect ratio before the file loads.

When should alt be empty?

When the image is purely decorative; alt="" tells screen readers to skip it. Missing alt is an error.

IMPWhat does the viewport meta tag fix?

Without it, mobile browsers lay out the page at about 980px wide and zoom out, so media queries and readable text fail.

defer vs async on a script?

Both download in parallel. defer runs after parsing, in order; async runs as soon as it arrives, in any order.

IMPRank the specificity: #nav a, .menu .item a, a:hover.

#nav a = 1,0,1 (highest), .menu .item a = 0,2,1, a:hover = 0,1,1.

IMPWhat does box-sizing: border-box change?

width and height include padding and border, so a 200px box stays 200px whatever its padding.

Why might a vertical gap be 30px when margins are 20px and 30px?

Vertical margins between adjacent blocks collapse to the larger one.

IMPWhat is the difference between display: none and visibility: hidden?

display: none removes the box from layout and the accessibility tree; visibility: hidden keeps its space but makes it invisible.

IMPAn absolutely positioned element is placed relative to what?

Its nearest ancestor whose position is not static (else the initial containing block).

Why can z-index: 999 lose to z-index: 2?

The 999 element is inside another stacking context (created by opacity, transform...) that is itself below the z-index: 2 element.

IMPFlexbox or grid for a page layout with header, sidebar, main and footer?

Grid: two-dimensional, with grid-template-areas. Flexbox suits one-dimensional rows such as the nav inside the header.

IMPWhat does repeat(auto-fit, minmax(200px, 1fr)) do?

Creates as many columns of at least 200px as fit, stretching them to fill the row: a responsive grid without media queries.

What does flex: 1 mean?

flex-grow 1, flex-shrink 1, flex-basis 0%: items share the space equally.

IMPrem vs em?

rem is relative to the root font size; em to the element's own (or for font-size, the parent's) font size, so it compounds when nested.

Why use 100dvh instead of 100vh on phones?

100vh is the largest viewport (browser bars hidden), so content overflows when the bars show; dvh follows the actual visible height.

IMPWhich properties are cheap to animate?

transform and opacity (also filter): they skip layout and paint and run on the compositor.

What does :where() do differently from :is()?

Same matching, but :where() always has specificity 0, so it is easy to override.

IMPWhat can :has() do that older CSS could not?

Select an element based on what it contains or what follows it: a parent selector, e.g. .card:has(img) or form:has(:invalid).

When do media queries and container queries each fit best?

Media queries for page-level layout decisions based on the viewport; container queries for reusable components that adapt to the space they are placed in.

What is the cascade order of unlayered styles vs @layer styles?

Unlayered author styles beat all layered ones; between layers the later-declared layer wins (reversed for !important).
